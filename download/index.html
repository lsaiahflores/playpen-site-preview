Download for Windows

The installer comes from this project’s public releases page on GitHub. Nothing is signed up for or tracked here.

What you need

  • Windows 10 or 11, 64-bit.
  • Memory: 8 GB works with a small local model. 16 GB or more is better. 32 GB runs the bigger models well.
  • Disk space: a few gigabytes for Playpen’s tools and a first model, and more if you choose a bigger local model.
  • Internet for the first-time setup, and for Claude if you use it.
  • For Claude or Hybrid mode: a paid Claude plan (Pro, Max, Team or Enterprise) or an API account, since Claude Code needs one. Local mode needs no account.

If Windows says it protected your PC

When you run the installer, Windows may show a blue box that says Windows protected your PC. Click More info, then Run anyway.

This happens because Playpen’s installer isn’t code-signed yet. Code-signing certificates cost money, and Playpen is free and just getting started. Windows shows that warning for any new, unsigned app.

To check that your file is the real one, compare its checksum with the SHA-256 shown above. In PowerShell:

Get-FileHash .\Playpen-Setup-*.exe -Algorithm SHA256

After you install

The first time you open Playpen it sets up the tools it needs and picks a local model that fits your computer. That takes a few minutes and needs the internet. After that you just say what you want to make.
